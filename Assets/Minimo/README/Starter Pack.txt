# 🌟✨ MINIMO STARTER PACK – Free Character & Essential Controls ✨🌟

A free introduction to the MINIMO character system for Unity.

**MINIMO STARTER PACK** provides one ready-to-use stylized character, a modular Character Editor demo, and a playable Playground scene containing the essential third-person movement systems shown in the package preview.

Use it to test the MINIMO workflow, prototype a platformer or adventure game, study the included character controller, and confirm that the visual style fits your project before expanding your collection with additional MINIMO character packs.

---

## 🎯 WHAT IS INCLUDED?

The Starter Pack contains:

* 1 free MINIMO character
* 1 Character Editor scene

Some areas of the Character Editor may display previews or promotional links for other MINIMO collections. Characters, outfits, props, and parts belonging to those separate collections are not included in the Starter Pack and must be obtained separately.

## 🛠️ CHARACTER CUSTOMIZATION WORKFLOW

1. Open the Character Editor scene.
2. Enter Play Mode.
3. Select **Customize**.
4. Choose a body-part category from the colored category buttons.
5. Select one of the available part thumbnails.
6. Use the color presets to recolor the selected part.
7. Use the custom color control when a more specific color is required.
8. Use the **None** option to remove an optional part when supported.
9. Use the randomization controls to create a quick variation.
10. Press **Save** to store the current character setup.
11. Open **Saved Prefabs** to view saved character presets.
12. Press **Play** to test the selected character in the Playground scene.

The editor also demonstrates linked-part editing. Related body pieces can be kept visually synchronized so connected sections of an outfit can share coordinated changes instead of being edited one by one.

Examples include linked torso, shoulder, and arm sections. The available linked parts depend on the selected modular item.

## 🏃 MOVEMENT SYSTEM DETAILS

### Walk and Sprint

Use standard directional movement for walking. Hold **Left Shift** while moving to sprint.

### Short, Long, and Double Jump

The Playground contains separate marked areas for testing the controller’s jump variations, including short jumps, longer jumps, and an additional mid-air jump.

### Dash

Press **Q** to perform a fast directional dash. The Playground includes sections where jumping and dashing are combined to cross larger gaps.

### Roll

Press **Left Alt** to perform a forward roll. Rolling can be used as an evasive or traversal action and is demonstrated in open sections of the Playground.

### Crouch and Slide

Press **C** to crouch. When used with movement conditions supported by the controller, the same input can initiate a slide. Low-clearance tunnels are included to test crouched traversal.

### Climb

The character can interact with designated climbable surfaces shown in the Playground.

### Wall Jump

The wall-jump section demonstrates repeated jumps against vertical surfaces to gain height.

### Ground Pound

While airborne, press **E** or **Left Ctrl** to perform the ground-pound action.

### Bounce Surfaces

The purple rounded obstacles demonstrate character reactions and airborne movement when crossing spring-like surfaces.

## 🚀 QUICK START

1. Import **MINIMO STARTER PACK** into your Unity project.
2. Allow Unity to complete script compilation and asset import.
3. Locate the package’s Scenes folder.
4. Open the Character Editor scene to customize and save the free character.
5. Open the Playground scene to test the included movement controller.
6. Enter Play Mode.
7. Press **F2** at any time in the Playground to show or hide the control reference.
8. Press **F1** to show or hide the performance information.
9. Use **Escape** to return to or open the character customization interface where supported.
10. Duplicate the included example character or prefab before making major project-specific changes.

For production use, integrate the controller, character prefab, animations, and camera into a copy of your own scene rather than editing the original demo scene directly.

## 🔧 TROUBLESHOOTING

### The Character Does Not Move

* Confirm that the Game window is focused.
* Verify that the character controller and input components are enabled.
* Check that the project has completed script compilation without errors.
* Confirm that the required input configuration is active.

### The Camera Does Not Follow the Character

* Verify the camera target or follow reference.
* Confirm that the demo camera object is enabled.
* Check whether another camera in the scene is active.

### The Character Falls Through the Floor

* Confirm that the floor has a collider.
* Verify the character’s ground and collision layers.
* Check the controller’s ground-detection settings.

### Animations Do Not Play Correctly

* Confirm that the supplied Animator Controller is assigned.
* Verify that animation references have not been removed.
* Check the Console for missing parameter or state errors.

### Climb or Wall Jump Does Not Activate

* Test the action on the designated Playground surfaces first.
* Verify the required collision layers, tags, or surface settings.
* Confirm that the character is positioned and moving toward the surface correctly.

### A Customized Part Is Missing

* Confirm that the MINIMO package containing that part is installed.
* Reopen the Character Editor after Unity finishes importing.
* Check whether the part is optional or currently set to **None**.

### Materials Appear Incorrect or Pink

* Confirm that the project’s render-pipeline setup matches the materials being used.
* Reimport the package after the project has finished compiling.
* Convert or upgrade a duplicated material only when required by your project pipeline.

### A Saved Preset Contains Unavailable Parts

* Install the MINIMO package that owns those parts, or replace them with Starter Pack content.
* Save the preset again after all missing references have been resolved.
